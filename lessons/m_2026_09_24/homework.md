# Часть 2. Типы данных в Python

Тип данных — это **что за значение** лежит в переменной и **что с ним можно делать**.
С числами можно считать, со строками — склеивать. Если перепутать типы, Python выдаст ошибку.

Узнать тип можно всегда:

```python
print(type(5))        # <class 'int'>
print(type("привет")) # <class 'str'>
```

---

## 1. `str` — строка (текст)

Текст в кавычках. Кавычки одинарные и двойные равноправны.

```python
name = "Себастьян"
print(len(name))              # 9 — длина строки
print(name + "!")             # склейка
print(f"Привет, {name}!")     # f-строка — главный способ собрать текст
print(name.upper())           # СЕБАСТЬЯН
print(name[0])                # С — нумерация символов с нуля
```

**Важно:**
- Всё, что вводит пользователь через `input()`, — строка, даже если он ввёл число.
- Номер телефона и почтовый индекс хранят строкой: там бывают `+` и ведущие нули.
  Правило простое: **если с данными не нужна математика — это строка.**
- Строку нельзя изменить по частям, методы вроде `.upper()` возвращают **новую** строку.

---

## 2. `int` — целое число

Числа без дробной части: `0`, `7`, `-15`. С ними работает вся арифметика.

```python
a = 7
b = 2
print(a + b)   # 9
print(a / b)   # 3.5  — обычное деление, всегда даёт float
print(a // b)  # 3    — целая часть от деления
print(a % b)   # 1    — остаток от деления
print(a ** b)  # 49   — возведение в степень
```

`//` и `%` нужны чаще, чем кажется: например, перевести 130 секунд в «2 мин 10 сек» —
это `130 // 60` и `130 % 60`.

---

## 3. `float` — дробное число

Числа с точкой: `3.14`, `0.5`, `-2.0`. Разделитель — **точка**, не запятая.

```python
price = 99.9
print(price * 2)    # 199.8
print(round(3.14159, 2))  # 3.14 — округление до 2 знаков
```

**Главная странность, которую надо просто знать:**

```python
print(0.1 + 0.2)          # 0.30000000000000004, а не 0.3
print(0.1 + 0.2 == 0.3)   # False !
```

Компьютер хранит дроби приблизительно. Поэтому дробные числа **не сравнивают через `==`**,
а для вывода округляют: `round(0.1 + 0.2, 2)`.

---

## 4. `bool` — логический тип

Всего два значения: `True` и `False`. Появляются сами при сравнениях.

```python
age = 15
print(age > 18)        # False
print(age == 15)       # True
print(age != 15)       # False

print(True and False)  # False — «и»: нужно, чтобы оба были True
print(True or False)   # True  — «или»: достаточно одного
print(not True)        # False — «не»: переворачивает
```

Не путай: `=` — присвоить значение, `==` — сравнить.

Ещё Python умеет считать «ложным» пустое: `0`, `""`, `[]` ведут себя как `False`,
а любое непустое значение — как `True`.

---

## 5. `None` — «значения нет»

Это не ноль и не пустая строка, а специальная пометка «ничего не известно / не задано».

```python
middle_name = None
print(middle_name is None)   # True
```

Проверяют его через `is None`, а не через `==`.

Разница важна: если в поле «сколько денег» лежит `0` — денег нет.
Если лежит `None` — мы просто **не знаем**, сколько там.

---

## 6. `list` — список

Несколько значений в одной переменной, по порядку, в квадратных скобках.

```python
marks = [5, 4, 5, 3]

print(marks[0])       # 5  — первый элемент, нумерация с нуля
print(marks[-1])      # 3  — последний
print(len(marks))     # 4  — сколько элементов

marks.append(4)       # добавить в конец
marks[1] = 5          # заменить элемент — список изменяемый!
print(marks)          # [5, 5, 5, 3, 4]

print(sum(marks))     # сумма
print(max(marks))     # максимум
print(sorted(marks))  # отсортированная копия
```

В списке могут лежать любые типы, в том числе разные сразу: `["Себастьян", 15, True]`.

---

## 7. Превращение одного типа в другой

Это самое частое место ошибок у новичков.

```python
age_text = input("Сколько тебе лет? ")   # это СТРОКА, даже если ввели 15
age = int(age_text)                      # теперь число, можно считать
print(age + 1)

print(str(15) + " лет")   # число -> строка, чтобы склеить
print(float("3.5"))       # строка -> дробное число
print(int(3.9))           # 3 — дробная часть отбрасывается, без округления!
```

Что будет, если типы перепутать:

```python
print("15" + 1)   # TypeError — строку и число сложить нельзя
```

---

## 8. Что ещё бывает (просто знать, разберём позже)

- **`Decimal`** — «честные» дроби для денег. Там, где `float` даёт `0.30000000000000004`,
  `Decimal` считает копейки точно. Нужен в магазинах, банках, чеках.
- **`datetime`** — дата и время как отдельный тип. Позволяет складывать и вычитать даты:
  например, узнать, сколько дней осталось до Нового года.

Сейчас их учить не надо — просто помни, что они существуют.

## Шпаргалка

| Тип | Что хранит | Пример | Особенность |
|---|---|---|---|
| `str` | текст | `"Привет"` | нельзя изменить по частям |
| `int` | целое число | `42` | `//` и `%` для деления нацело |
| `float` | дробное число | `3.14` | считает неточно, `==` не использовать |
| `bool` | да / нет | `True` | результат сравнений |
| `None` | «значения нет» | `None` | проверять через `is None` |
| `list` | список значений | `[1, 2, 3]` | изменяемый, индексы с нуля |

**Три правила, которые стоит запомнить:**
1. `input()` всегда возвращает строку — для математики оборачивай в `int()` или `float()`.
2. `float` не сравнивают через `==`.
3. Не знаешь, что в переменной, — напечатай `type(переменная)`.
